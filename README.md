# AI Trading OS

AI Trading OS is a production-style trading platform backend built with Python and FastAPI. The project follows clean architecture principles and integrates live cryptocurrency market data to power technical analysis, market scanning, portfolio management, and AI-driven trading insights.

## 🚀 Features

- Live Cryptocurrency Market Data (Binance API)
- FastAPI REST API
- Repository Pattern & Service Layer
- Pydantic Data Models
- Environment-based Configuration
- Structured Logging
- Unit & Integration Testing (Pytest)
- Technical Indicators (Upcoming)
- Market Scanner (Upcoming)
- Portfolio Tracking (Upcoming)
- AI Trading Assistant (Upcoming)

## 🛠 Tech Stack

- Python 3.11+
- FastAPI
- Pydantic
- Requests
- Pytest
- Uvicorn
- Git & GitHub
